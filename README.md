# Dabang Sales Dashboard

Monorepo for a sample sales dashboard built with Next.js and NestJS.

## Apps

- **web** – Next.js frontend.
- **api** – NestJS backend.

## Development

```bash
pnpm install
pnpm dev:web     # start Next.js
pnpm dev:api     # start NestJS
```

## Environment

Create `.env` from `.env.example`.

## Testing

```
pnpm test
```
